# MAYA · The Artificial Self
Run backend: `cd backend && python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && export GEMINI_API_KEY=your_key  # optional && uvicorn main:app --reload`
Run frontend: `cd frontend && npm install && npm run dev` → http://localhost:5173
No API key? MAYA still works with a built-in honest offline voice (memories, personality, emotion all still evolve).
Demo: Enter → "Hi MAYA, my name is Arun and I'm an engineering student." → "I love artificial intelligence and I want to build something meaningful." → Artificial Self → "Do you actually feel emotions?" → "Who are you?" → Evolution → Reality Reveal.
